Kodi for iOS · Design mockups · v1

Settings, rebuilt the iOS way

The current settings screen is the landscape arctic.fuse skin squeezed into a portrait phone. These mockups replace it with a native iOS 27 grouped-list layout that matches the system Settings app: inset rounded groups, black icon tiles with coloured glyphs, a glass back button, the floating search bar, iOS 26 toggles and grey footer notes. Tap any row with a chevron to jump to its screen.

Design specs for implementation

Colours (dark)

  • Background #000000
  • Group cell #1C1C1E
  • Separator #38383A · 0.5pt
  • Secondary text #8E8E93
  • Tint / links #0A84FF
  • Toggle on #30D158
  • Badge / destructive #FF453A

Layout

  • Group inset: 16pt sides · radius 26pt
  • Row min height: 52pt · padding 16pt
  • Space between groups: 34pt
  • Separator starts at text (after icon)
  • Icon tile: 31pt · radius 9pt · glyph 19pt
  • Back button: 46pt glass circle

Type (SF Pro)

  • Row label: 17pt Regular
  • Value: 17pt Regular · secondary
  • Nav title: 17pt Bold
  • Section title: 17pt Bold · secondary
  • Footer: 13pt · secondary
  • Hero title: 30pt Heavy

Building it natively

  • SwiftUI List + .insetGrouped
  • NavigationStack for push pages
  • .searchable → bottom glass search bar
  • Values read/written via Kodi settings (JSON-RPC Settings.*)
  • Respects Settings Level & Dynamic Type
