# Settings Redesign Mockups

Open `index.html` in a browser (or on iPhone) to see the mockups. Nothing here is app code yet.

The new Settings UI copies the native iOS 27 Settings app: inset grouped lists, black icon tiles with coloured glyphs, a glass back button, the floating search bar and iOS 26 toggles. It replaces the letterboxed arctic.fuse settings screen (`current-settings.png`).

Screens:
1. Settings Home (root)
2. System (category page with a hero card)
3. System › Display (detail page with an inline pick-one list)
4. Customisation (styled like Appearance)
5. Player (sections and a subtitle preview)
6. Add-ons hub (styled like Apple Account)
7. Add-on Updates (styled like Software Update)
8. Information (styled like About and Storage)

The design specs (colours, spacing, type) are at the bottom of `index.html`.
