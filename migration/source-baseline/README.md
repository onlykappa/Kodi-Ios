# Preserved Elementum dependency sources

These four unmodified source trees come from the existing Elementum source lock. The manifest records the original repository, commit, Git tree, archive SHA256 and byte size. Every archive retains its `LICENSE.txt`, source copyright notices and packaged assets. The two autocompletion packages declare GPL-2.0-or-later, kodi-six declares GPL v3, and inputstreamhelper declares MIT; their included license texts govern the corresponding files. No source modifications are made in these archives. Retain all notices on redistribution and supply the matching source with GPL-covered distributions.

Archives are stored through Git LFS in this same private repository. After cloning, run `git lfs pull`, then `python3 -B scripts/test_source_offline_restore.py` to extract into temporary directories and independently compare each restored Git tree against the upstream pin. An absent LFS object, pointer-only checkout, tampered archive or changed source tree fails verification. This test performs local Git operations without fetching upstream repositories.

This is a partial dependency-source backup, not a complete app or native engine build. `script.module.future` is excluded because its original tree contains test private keys and certificate fixtures; preserving it requires an explicit reviewed treatment of those public test fixtures. Provider archives, third-party artwork, the Otaku database, clients and native engine build dependencies remain outside this preserved subset. Existing installed app behavior is unchanged.
