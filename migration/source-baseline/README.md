# Preserved Elementum dependency sources

These four unmodified source trees come from the existing Elementum source lock. The manifest records the original repository, commit, Git tree, archive SHA256 and byte size. Every archive retains its `LICENSE.txt`, source copyright notices and packaged assets. The two autocompletion packages declare GPL-2.0-or-later, kodi-six declares GPL v3, and inputstreamhelper declares MIT; their included license texts govern the corresponding files. No source modifications are made in these archives. Retain all notices on redistribution and supply the matching source with GPL-covered distributions.

Archives are stored through Git LFS in this same private repository. After cloning, run `git lfs install --local` and `git lfs pull`, then `python3 -B scripts/test_source_offline_restore.py` to extract into temporary directories and independently compare each restored Git tree against its recorded upstream or sanitized tree hash. An absent LFS object, pointer-only checkout, tampered archive or changed source tree fails verification. This test performs local Git operations without fetching upstream repositories.

This is a partial dependency-source backup, not a complete app or native engine build. The original `script.module.future` tree remains excluded; a separately identified sanitized snapshot is described below. Provider archives, third-party artwork, the Otaku database, clients and native engine build dependencies remain outside this preserved subset. Existing installed app behavior is unchanged.

`script.module.future.zip` is a **modified runtime snapshot**, not the upstream Git tree. `future-transform.json` lists the 14 removed public test certificate/key fixtures; six credential-shaped proxy doctest calls and their expected lines were removed from `urllib/request.py`. Executable statements and the MIT license remain. Reproduce the archive from the exact locked tree with `python3 -B scripts/snapshot_future.py <upstream-script.module.future-directory> <output.zip>`; the script verifies the original tree first. The manifest records both upstream and transformed Git tree hashes. The offline Elementum restorer accepts this exact transformed tree separately; upstream test fixtures and those doctests are unavailable in the snapshot. Isolated host Python import checks do not prove Kodi or iOS compatibility.
