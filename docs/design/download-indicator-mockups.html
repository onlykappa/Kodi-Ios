Downloads, where you can see them

Today Elementum's download shows as Kodi's background progress box: Fuse's tiny landscape strip ("Elementum · INCEPTION.2010.PROPER.BLURAY.2… - 446 KB/S - 0 B/S - 10%") squeezed into whatever page is open, in a different spot on each one. This replaces it with one glass pill that always sits in the same place: just above the tab bar, or at the bottom of pages without one. It shows a progress ring, the movie's name instead of the file name, speed and time left. Tap it to open Notifications › Downloads, or tap ❚❚ to pause.

Other placement: under the Dynamic Island

For comparison: a black pill hanging under the Dynamic Island, like iOS Live Activities. It stays out of the content on every page, but it sits next to the clock and the large titles, and it's harder to tap. I recommend above the tab bar (mockups above). Pick whichever you prefer.

How it would be built

What it replaces

  • Kodi's background progress box (DialogExtendedProgressBar), which Elementum opens for each download
  • Hidden for Elementum; other add-ons' background progress uses the same pill

Where the data comes from

  • The notification center already reads Elementum's engine (/torrents/list): title, %, speed, paused
  • Drive upload progress from driveupload

Placement

  • Tab pages: 8 pt above the tab bar
  • Other pages: bottom edge, above the home indicator
  • Full-screen pages: compact, top centre
  • Video: compact, only with the controls

Size (iPhone points)

  • Pill 62 pt, inset 14 pt, radius 31 pt
  • Ring 46 pt, 3.5 pt stroke
  • Compact 44 pt
  • Progress hairline along the bottom edge
