New header buttons: bell, gear, refresh and back

Today the bell and the profile picture are flat dark circles, and the blue "busy" ring is a thick arc that looks cut off (your first screenshot). The refresh icon has no button around it, and the back arrow sits on a two-tone panel. These mockups redraw all four as one family of iOS 26 Liquid Glass buttons with SF Symbols-style icons. The gear replaces the profile picture and opens Settings. The new refresh button sits on Home, Movies and TV and swaps every row for different titles. The same glass back button goes on every page that has one, like the pill.

How refresh works

What changes

Every row that comes from TMDb Helper or Trakt (Trending, Popular, Because You Watched, genres…) and the hero spotlight. Each row asks its list for a different page of results (page 2, then 3…). When a list runs out it starts again from the top, so you always get titles you haven't just seen.

What never changes

Continue Watching, Up Next, Downloaded, your own library rows and playlists. These follow what you watch, so shuffling them would only lose your place.

Per page

Refresh on Home changes only Home; Movies and TV each keep their own page number. The next start keeps the last pages you picked, so a refresh sticks until you refresh again.

Option: shuffle

If you'd rather mix than page through, a switch in Settings › Customisation › Tabs & Rows can make refresh pick a random page each time. Next page is the default because it never repeats until a list runs out.
