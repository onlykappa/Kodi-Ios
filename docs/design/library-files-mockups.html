Library › TV Shows and Movies

Owner, 2026-11-12: "currently it just takes me to downloaded movies but instead i want a way to view like the details of shows and movies like if i click on a show it will show the episodes and all that then if i click on a episode it tells me it's converted ready blah blah and a easy way to delete files! Like a professional file manager but make it so pretty!"

The Library's TV Shows and Movies tabs become one file manager for everything downloaded (Google Drive and this iPhone): what you have, how much room it takes, what state each file is in, and a safe way to delete. Same dark grouped style as Settings; poster art is grey/colour placeholders here. Deleting always asks first and sends Drive files to Drive's Trash (30 days), as the long-press Remove does today.

A · LIBRARY › TV SHOWS

Every downloaded show, its size and its state

A TV Shows / Movies switch at the top. A storage card: Google Drive used, split into shows, movies and AI copies, and this iPhone. Search and sort (Recent, Name, Size). Each show: poster, name, seasons and episodes, total size, and chips for the state: green ready, orange still converting, purple AI copy, red a problem. Tap a show for board B.

Notes

  • Kodi limits (APPLE-UI-POLICY §2): this is Kodi skin XML, not UIKit. The switch, chips, bars, checkboxes and sheet are drawn with the existing portrait helpers (season sheets, Settings rows, the IOSSkinList second line).
  • States come from what the app already records: debrid_drive (copying to Drive), the preparation queue (converting, ready, problem), upscale-copies.json (AI copies), the phone's completed downloads, Continue Watching (watched).
  • Delete reuses ios_remove (long press › Remove): Drive files to Drive's Trash, phone files deleted, Library listing and Continue Watching cleaned. New: several at once, and AI copies with their originals.
  • Numbers and names are examples; artwork is placeholder colour.
