Poster cards: art and fallbacks

Apple TV app artwork cannot be copied (it is Apple's licensed art and has no public API), so these options get the same look from TMDb art: landscape, fanart, poster and clearlogo. Every card shows a red MISSING tag where TMDb has no image, so you can compare how each option handles it. All art here is drawn with CSS gradients.
