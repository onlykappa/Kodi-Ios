# Sports › Upcoming: what the page needs from the foundation

Read off the approved Upcoming page and the game page ([sports-approved-pages.html](sports-approved-pages.html), DEC-056). It says nothing
about how any add-on works. Like Live Now, it is **one combined answer** for all add-ons, and the combining rules of DEC-055 apply
(one game from many add-ons, one line per stream, Best / Also good).

## For each upcoming game

| On screen | Needs |
|---|---|
| Day heading ("Today", "Tomorrow", "Sat, Nov 21") and its count | the start date, in the phone's time zone (the foundation sends a time; the page makes the heading) |
| Start time ("7:30 PM") | the start time; "in 45 min" is made on the phone when it is under an hour away |
| League label | the same short code as Live Now |
| Who plays whom | the same names and joiner ("vs" or "at": away team at home team) as Live Now |
| "2 sources" / "No sources yet" | how many sources have been found so far (0 is normal for a game days away) |

## The game's page

- the teams, the league label, the start time and how long until it starts;
- the sources found so far, best first, in the same shape as Live Now's (add-on, picture size and language, the Best / Also good tag, the
  other add-ons with the same stream, and what to play). A tap plays at once.

## Rules from the screens

- Sorted by start time, soonest first. A game that has started leaves this list and appears in Live Now (the foundation says "live", the
  pages do not guess).
- The page opens at once from the last answer it has and refreshes behind it; one slow or failing add-on never blanks it.
- Names and times are short or wrap; nothing is cut off (DEC-050).
