Every add-on page

Seven pages that surround the add-on page (see addon-info-mockups.html). They come from the screens you screenshotted and the tap logs: Add-ons, My add-ons, Available updates, Install from repository, Install from zip file, Search and Event log. All of them use the same pattern as the other portrait pages: back chevron, grouped rows, one white button for the main action.

Add-on names, versions and counts are sample text. Tiles are letters or generic glyphs, because each add-on supplies its own icon at runtime.
