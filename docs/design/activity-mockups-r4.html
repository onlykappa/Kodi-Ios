Pill states · drawn at real size
  • ISSUE-102Progress is a ring around the app tile, filling clockwise. The empty grey badge on the tile's corner is gone. If there's no percentage, the same ring spins, so the indicator stays in the same place and shape (HIG progress indicators).
  • ISSUE-102Every control is 44 pt. The pause disc is drawn at 34 pt inside a 44 pt touch area (turn on the toggle above to see the areas). In Kodi units that's 118, against 104 and 96 today.
  • One line of each kind, never two labels in one place. The title is bold 16 pt. The status line is 13 pt and starts with the percentage, so if it gets cut off, the time left goes first, not the progress.
  • The pill is drawn by Kodi, so it's an almost solid surface (96 %) with a hairline edge, not a blur. Only the native tab bar under it is real Liquid Glass.

2 · Activity sheet

Opened from the pill or the bell
  • Close (✕) instead of Done. The sheet only shows status and has nothing to save. HIG reserves Done for finishing a task. Swiping down and tapping the dimmed page also close it.
  • Grouped by kind (Downloading, Preparing for AirPlay, Uploading to Drive), with each group's count in its header, said once.
  • Rows match the pill: the same ring tile, the same two lines, and a pause control with a 44 pt touch area. Paused rows show their percentage in grey, plus a play glyph.
  • The sheet's height follows its rows up to about half the screen (iOS medium height), then it scrolls.
  • Blue has two jobs. Fills (rings, the selected tab, app tiles) use system blue #0A84FF. Small blue text uses #4FA8FF (5.6 : 1 on the sheet) because system blue fails there at 3.8 : 1. Owner to confirm.

3 · Notifications

All · live work first, then earlier messages. Try the filter.
Problems · each with one way to fix it
  • ISSUE-101No text overlaps. Each card is title, summary, bar, status, one label per line. The "then off the phone" hint now sits in the summary instead of on top of the status. This matches the fix pushed to PR #10.
  • ISSUE-101Readable titles: Lanterns.S01E01.Pilot.2160p… becomes "Lanterns · S1 E1". The "8 remaining" count appears once.
  • Pause and Cancel are 44 pt capsules. Cancel is red because it loses progress (HIG: say when stopping has a cost).
  • Timestamps and section counts use readable grey. The 30 % grey they used before is too faint for text (2.2 : 1).
  • Problems explain what happened and offer one action (Retry, Sign in, Free up space). Raw errors and file paths stay in the log.
