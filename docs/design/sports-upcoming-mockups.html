Sports › Upcoming · round 3

What this is. The page behind the blue Upcoming tile: the games that have not started yet, soonest first, a day at a time (Today, Tomorrow, then the date). Each game shows its league label, who plays whom, when it starts (and “in 45 min” when it is close) and how many sources the four add-ons have found so far. The same league chips as Live Now filter it. A game that has started moves to Live Now by itself.

A tap on a game opens its page: the teams, the start time and the sources found so far (they play at once), or “No sources yet”. Times are in the phone’s own time zone. Evidence class: mockup, not Kodi.

To decide

  • Which list? A, a compact list by day (I recommend it: more games on a screen), or B, cards like Live Now.
  • A tap on a game opens its page, as drawn. Or should a game with a source play at once, like Live Now?
