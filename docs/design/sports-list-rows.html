Sports lists: one line per game

Today a game is a long title that wraps, plus a second line ("No sources yet", league badge). These options follow the Apple Sports "Today" list: team crest and short name on each side, the time in the middle, the league moves to a group header, and "No sources yet" is dropped (a small green dot appears only when a source is found). Every option stays a single row of the same height, so the list scans like a scoreboard.

Pick A, B or C for the list rows, and A or B for the Up next card. The same row is then used on Upcoming, Today, Yesterday and the league pages.

A · Scoreboard rows. Closest to Apple Sports. Crest, short name and record each side; time in the middle with the broadcaster under it (the one small line left, as in Apple Sports; the green dot replaces "No sources yet"). League is the group header, so no badge per row. Row height is fixed (about 20 pt over today).
