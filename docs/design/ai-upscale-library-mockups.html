Notes

  • Kodi skin XML with the existing helpers: Settings grouped rows and section headings (status_ui), the Library status work card and copy-lane rows, the thin progress bar (§4.7), the round pause control (118-unit touch area, ~92 drawn), the status sheet with ✕, the red text action and the standard alert. No new colours, radii or button styles; the heading link uses the text blue 4FA8FF.
  • AI Upscale data already exists: upscale_queue (copies, status, error/reason, estimate), upscale_cloud progress, picture settings. New behaviour: pause / cancel one copy, remove from Up next, Cancel All, and merging a show's TMDb and name-only groups.
  • Cancel and Remove never touch the original video. Clear on Download problems only empties that list.
  • Numbers and titles are examples; artwork is placeholder colour.
