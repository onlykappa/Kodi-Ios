Installing add-ons: the rest of the pages

The pages for the second half of installing: the zip file route (frames 1 to 3), the install and download progress (4 and 5), the finished and failed states (6 and 7), and The Crew's own window (8). Same pattern as the earlier boards: grouped rows, one white primary capsule, thin progress bars, the dark sheet and alert card.

The iPhone Files picker is Apple's own screen, so it is not drawn here: "Choose from Files" in frame 1 opens it. Names, sizes and versions are sample text.

How it will be built (for review)

Frames 1 to 3 are one Python-driven sheet flow (the project's choice sheet) that lists the zips Kodi can see, unpacks the chosen zip into Kodi's add-ons folder, asks Kodi to add and enable it and installs any missing dependencies from the repositories. "Choose from Files" needs a small native iOS file picker added to the app, which can only be built and tested on a Mac build, so it would arrive untested and clearly marked. Frames 4 to 7 reuse Kodi's own install and its progress. Frame 8 replaces one file of The Crew's pinned version, as for The Loop. No new colour, font size, radius or button variant.
