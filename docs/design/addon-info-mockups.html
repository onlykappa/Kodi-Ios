Add-on page, one design for every add-on

Today, tapping an add-on in My add-ons opens Arctic Fuse's landscape DialogAddonInfo squeezed into the phone: a small dialog, tiny type, a column of five small buttons, a description that cuts off mid-sentence and a scroll area inside a dialog.

Proposed: a full portrait page, the same pattern as the other portrait pages (back chevron, grouped rows, one white primary capsule). The same layout serves every add-on. What changes per add-on is only its data (icon, name, author, version, description) and which actions apply, so Open, Install, Update and Enable are the same slot with different wording. Nothing is truncated: long names and descriptions wrap and the whole page scrolls. Three states follow, plus the Versions sheet and a scrolled view.

Add-on names and descriptions below are sample text only. Tiles use a letter or a generic puzzle piece, because each add-on's own icon is supplied by the add-on at runtime.
